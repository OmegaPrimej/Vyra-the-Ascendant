### Your first Termux commands

After downloading the ZIP into Downloads:

```bash
termux-setup-storage
pkg update -y
pkg install -y git gh unzip openjdk-17

cd ~/storage/downloads
unzip -o Vyra-Vera-Ascendant-Full-Project.zip
cd Vyra-Vera-Ascendant

git init
git add .
git commit -m "VYRA VERA Ascendant Digital Soul Foundation"
gh auth status
```

Then create the repository:

```bash
gh repo create OmegaPrimej/Vyra-Vera --private --source=. --remote=origin --push
```

GitHub Actions will build the debug APK.

Important: The memory foundation has redundant local copies, but they are not encrypted yet. Don't store sensitive personal information in this first build. The app also isn't yet connected to an actual AI model or quantum computer.
